```typescript
export interface DemonRowListProps {
  readonly listId: 'browser' | 'focus'
  readonly source: DemonRowSource          // already filtered + ordered by the parent; the parent remounts this list (React key) when the source changes
  readonly ariaLabel: string
  readonly selectedMesh: number | null     // pinned/focused demon: gets the UI-SPEC selected token and aria-selected="true"
  readonly revealIndex: number | null      // absolute index to scroll to (align 'center') and mark data-active
  readonly revealNonce: number             // bump to reveal the same index again
  readonly sort?: DemonSort                // present -> A::B / MESH / TYPE headers are sort buttons
  readonly onSortChange?: (key: DemonSortKey) => void
  readonly onHoverDemon: (d: DemonRef | null) => void
  readonly onSelectDemon: (d: DemonRef) => void
}
```
Implementation:
- `const { base, zoneLabel } = useNumogramView()`. Never read `view` (this list works at base 666, where view is null).
- Window paging (T-05-17): `const [page, setPage] = useState(0)`; `const win = windowAt(source.count, page)`; `const pages = windowCount(source.count)`.
- `const scrollRef = useRef<HTMLDivElement>(null)`; `const virtualizer = useVirtualizer({ count: win.size, getScrollElement: () => scrollRef.current, estimateSize: () => ROW_HEIGHT_PX, overscan: 12, scrollMargin: ROW_HEIGHT_PX })`.
- Rows: `virtualizer.getVirtualItems().map(item => { const index = win.start + item.index; const d = source.at(index); ... })` — exactly one `source.at` per rendered row; never loop over source.count.
- Row element per the DOM contract, style `{ position: 'absolute', top: item.start - ROW_HEIGHT_PX, left: 0, width: '100%', height: ROW_HEIGHT_PX, display: 'grid', gridTemplateColumns: COLUMNS, alignItems: 'center' }` with
  `const COLUMNS = 'minmax(88px,1.1fr) minmax(72px,0.9fr) minmax(136px,1.5fr) minmax(88px,1fr)'`; className `px-2 text-[10px] leading-[1.4] cursor-pointer` plus `hover:bg-white/[0.03]` when not selected;
  selected rows get `background: 'rgba(16,255,80,0.08)', boxShadow: 'inset 0 -1px 0 rgba(16,255,80,0.4)'` (UI-SPEC: the one selected token, never a new one); no zebra striping.
  Cells: ab = netSpanLabel(d.a, d.b, zoneLabel) (label-scheme aware, research Pitfall 4); mesh = String(d.mesh) (decimal id, no grouping, so it can be pasted into search);
  type = SUBTYPE_LABEL[d.subtype] in color kindColor(d.subtype) (UI-SPEC: color via legacyKind, a syzygetic-chrono row is #e8e8e8); name = demonName(base, d.mesh) ?? '' (D-02: literally empty, the column stays).
  Events: onMouseEnter -> onHoverDemon(d); onMouseLeave -> onHoverDemon(null); onClick -> setActive(index), onSelectDemon(d).
- Header row (sticky, inside the scroll element, before the spacer): `className="sticky top-0 z-[1] grid px-2 text-[8px] uppercase tracking-[0.12em] text-gray-500"`, `style={{ height: ROW_HEIGHT_PX, gridTemplateColumns: COLUMNS, alignItems: 'center', background: 'rgba(8,8,15,0.97)' }}`.
  With `sort`, the A::B and MESH headers are `<button type="button" data-sort-col="ab"|"mesh" onClick={() => onSortChange?.('mesh')}>` and TYPE is `data-sort-col="type"` -> onSortChange('type');
  aria-sort on each columnheader: key match -> (direction 'asc' ? 'ascending' : 'descending'), else 'none'; A::B and MESH both reflect key 'mesh' (same total order, research).
  A direction glyph (U+25B2 / U+25BC built with String.fromCodePoint) sits in an aria-hidden span so the header text stays exactly `A::B`/`MESH`/`TYPE`/`NAME`.
- Spacer: `<div data-demon-rows-spacer="" style={{ height: virtualizer.getTotalSize(), position: 'relative', width: '100%' }}>{rows}</div>`.
- Scroll element: `<div ref={scrollRef} role="grid" ... tabIndex={0} className="h-full min-h-0 overflow-auto" style={{ outline: 'none' }}>`; track focus in state (`gridFocused`) to draw the active row outline `1px solid rgba(16,255,80,0.6)` (outlineOffset -1) only while the grid is focused.
- Keyboard (onKeyDown on the grid; preventDefault only for handled keys): ArrowDown/ArrowUp +/-1, PageDown/PageUp +/-20, Home -> win.start, End -> win.start + win.size - 1 (clamped to the window); then `virtualizer.scrollToIndex(active - win.start, { align: 'auto' })`. Enter or ' ' -> onSelectDemon(source.at(active)) (active defaults to win.start on first key).
- Reveal: `useEffect` on [revealIndex, revealNonce]: when revealIndex !== null, target page = Math.floor(revealIndex / BROWSER_WINDOW_ROWS); if it differs from page, setPage(target) and keep the index in a ref so a follow-up effect (on page) scrolls after the window changes; otherwise `virtualizer.scrollToIndex(revealIndex - win.start, { align: 'center' })`; setActive(revealIndex).
- Pager (pages > 1): below the grid, `div[data-demon-pager]` `className="flex items-center gap-2 pt-2 text-[10px] text-gray-400"` with text built as
  `` `Rows ${(win.start + 1).toLocaleString('en-US')}${EN_DASH}${(win.start + win.size).toLocaleString('en-US')} of ${source.count.toLocaleString('en-US')}` `` where `const EN_DASH = String.fromCodePoint(0x2013)`,
  and `<CyberButton size="sm" disabled={page === 0} onClick={...}>prev</CyberButton>` / `next`; changing page resets active to null and calls `virtualizer.scrollToOffset(0)`.
- Wrap everything in `<div className="flex h-full min-h-0 flex-col">` (grid flex-1, pager below).
- Row text is plain JSX text children only (T-05-18); no dangerouslySetInnerHTML.
