```typescript
export const SEARCH_MAX_LENGTH = 64
export const NAME_SEARCH_MAX_COUNT = 50_000   // ROADMAP Phase 5 note: name-based search only when the count is at most ~50k
export type DemonQuery =
  | { readonly kind: 'empty' }
  | { readonly kind: 'mesh'; readonly mesh: number }
  | { readonly kind: 'pair'; readonly a: number; readonly b: number }    // a > b
  | { readonly kind: 'name'; readonly mesh: number }
  | { readonly kind: 'not-found' }   // well formed, but no such demon (mesh >= count, zone >= base, a === b, unknown name)
  | { readonly kind: 'syntax' }      // none of the accepted forms
export function clampQuery(raw: string): string            // raw.slice(0, SEARCH_MAX_LENGTH)
export function parseZoneNumeral(text: string, base: number): number | null
export function parseDemonQuery(raw: string, g: Numogram): DemonQuery
```
Rules (T-05-07, T-05-08, T-05-09):
- parseZoneNumeral: t = text.trim(); base <= 36: t = t.toLowerCase() and require `/^[0-9a-z]{1,64}$/`; base > 36: require `/^\d{1,16}(?:\.\d{1,16}){0,15}$/`.
  Then `try { v = parseNumeral(t, base) } catch { return null }`; return `Number.isSafeInteger(v) && v < base ? v : null`.
- parseDemonQuery: text = clampQuery(raw).trim(); '' -> empty.
  `/^\d{1,16}$/` -> mesh = Number(text); `Number.isSafeInteger(mesh) && mesh < g.demons.count` ? mesh : not-found (mesh numbers are decimal integer ids).
  Else if text contains '::': split on the FIRST '::' only; if the right side still contains '::', or either side is empty after trim -> syntax;
  parse both sides with parseZoneNumeral; if a side fails its regex gate -> syntax; if a side is well formed but >= base -> not-found; a === b -> not-found;
  else pair with a = max, b = min.
  Else if `/^[a-z]{1,32}$/i.test(text)` and `demonNameTable(g.base) !== null` and `g.demons.count <= NAME_SEARCH_MAX_COUNT` (T-05-10): lower-case compare
  against the table in mesh order 0..count-1: exact match wins; else the first name starting with the text; none -> not-found.
  Else syntax.
- All regexes are anchored with bounded quantifiers (no nested unbounded groups), so matching is linear in the 64-char clamped text.
- Never use input text as a property key; the name table is read only by numeric mesh keys.

Write the Task 1 tests first in tests/app/demonSearch.test.ts (RED), then implement (GREEN).
