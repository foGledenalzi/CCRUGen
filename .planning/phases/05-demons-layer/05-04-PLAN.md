<objective>
Build the demon UI state model and its URL form: the shared focus state that both focus-mode entry points feed (D-03, DEM-03), the
chord list the main diagram draws for a focus, the base-switch sanitation rule (UI-08 precedent), and the D-07 URL params
`demonFilter=`, `demonFocus=`, `demonsOpen=1` in the single URL codec.

Purpose: D-03 requires one shared focus state for diagram->browser and browser->diagram; D-07 requires the filter and focused
demon/zone to be shareable. Decision (Claude's discretion from D-07): the overlay's open state IS shareable as `demonsOpen=1`, written
exactly when the overlay is open. It is not written "only when a filter or focus is active" (the UI-SPEC's tentative idea), because
that coupling would break the codec's parse(build(state)) === state round trip; each field stays independent and lenient like every
other field. The active tab and the matrix pan/zoom are not in the URL (D-07).
Output: `app/lib/demonState.ts`, the extended `app/lib/shareParams.ts`, and tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL query string -> ShareState | Anyone can hand-edit or craft a share link; demonFilter/demonFocus arrive as untrusted text |
| ShareState -> engine | Filter names reach g.demons.group()/subtype() (throw on unknown names); focus ids reach g.demons.ref() (throws on bad zones) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-12 | Tampering | parseDemonFilter | mitigate | Trimmed exact membership against DEMON_TYPES/DEMON_SUBTYPES before any engine call; unknown values (incl. `__proto__`, `constructor`) fall back to null ("All"), never thrown |
| T-05-13 | Tampering / DoS | parseDemonFocus | mitigate | Length cap 40, anchored `\d{1,10}` regexes, Number.isSafeInteger + `< base` + distinctness checks; invalid values dropped silently; 5,000-char hostile input tested |

| T-05-15 | Tampering (stale state) | demonsAfterBaseSwitch | mitigate | Focus always cleared on a base switch; a filter kept only when it has members at the new base |
| T-05-26 | Denial of Service | focusChordList / focusDrawPlan | mitigate | At most FOCUS_CHORD_DRAW_MAX = 4096 chords via strided O(1) incidentSource access; tested at base 2^20 |
