[default] decisions recorded here (review at the final checkpoint):
- CCRU canonical names are a read-time preset layer (user override > preset > derived), never copied into `overrides` (orchestrator decision 6; research A5 "as overrides" satisfied behaviourally).
- Override key = decimal mesh number in memory (`ReadonlyMap<number, string>`) and in JSON; no "a:b" form (orchestrator decision 7).
- Editing a sound locks its zone (UI-SPEC decision 8); setSeed/setStyle switch the source to 'generated'; setSource('ccru') loads the 10 preset sounds and clears locks; setSource('generated') regenerates unlocked zones keeping locks.
- Saving an override equal to what the rule or preset gives removes the override (UI-SPEC decision 11).
- `rev` (the history key) is NOT part of Naming: the app session owns it (plan 07-13).

The contract this plan creates (later plans use it verbatim):
```typescript
export type JoinOrder = 'hi-lo' | 'lo-hi'
export const JOIN_ORDERS: readonly JoinOrder[]            // ['hi-lo', 'lo-hi']
export function isJoinOrder(v: unknown): v is JoinOrder
export type NamingSource = 'generated' | 'ccru'
export type Smoothing = 0 | 1                              // 0 = off, 1 = euphony@1 (EUPHONY_VERSION)
export interface NamingMeta { readonly title: string; readonly notes: string }
export interface Naming {
  readonly base: number
  readonly source: NamingSource
  readonly seed: string                                    // normalized (normalizeSeed), always present
  readonly style: StyleId
  readonly join: JoinOrder
  readonly smoothing: Smoothing
  readonly sounds: readonly string[] | null                // dense, length base, when base <= interactiveMaxN; null = seed-only
  readonly locks: ReadonlySet<number>
  readonly overrides: ReadonlyMap<number, string>          // key = mesh number a(a-1)/2 + b
  readonly meta: NamingMeta | null
}
export interface NamingPreset { readonly id: 'ccru'; readonly base: number; readonly sounds: readonly string[]; readonly names: Readonly<Record<number, string>> }
export type NameState = 'generated' | 'preset' | 'overridden'
export interface NameResolver {
  readonly base: number
  soundOf(zone: number): string
  nameOf(a: number, b: number): string                     // order-free
  ruleNameOf(a: number, b: number, smoothing: Smoothing): string  // join + smoothing + capital, ignoring overrides and preset
  presetNameOf(a: number, b: number): string | null        // non-null only when the preset layer applies
  stateOf(a: number, b: number): NameState
}
export interface CreateNamingOptions {
  readonly base: number; readonly interactiveMaxN: number
  readonly source?: NamingSource; readonly seed?: string; readonly style?: StyleId
  readonly join?: JoinOrder; readonly smoothing?: Smoothing; readonly preset?: NamingPreset | null
}
```
