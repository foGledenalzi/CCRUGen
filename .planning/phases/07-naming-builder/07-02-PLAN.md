Create `engine/naming/text.ts` (header: D-07 rules, reason order, why the Segmenter is skipped for short strings):
- `export const SOUND_MAX_LENGTH = 16`, `export const NAME_MAX_LENGTH = 32`, `export const SEED_MAX_LENGTH = 64`
- `export type TextProblem = 'empty' | 'space' | 'digit' | 'other' | 'long'`
- `export type TextCheck = { readonly ok: true; readonly text: string } | { readonly ok: false; readonly reason: TextProblem }`
- `export function toNfc(s: string): string` (s.normalize('NFC'))
- `export function splitGraphemes(s: string): string[]`: on the NFC text, `new Intl.Segmenter(undefined, { granularity: 'grapheme' })`
  when `typeof Intl !== 'undefined' && typeof Intl.Segmenter === 'function'` (one module-level lazily created instance), else
  `text.match(/\P{M}\p{M}*/gu) ?? []`.
- `export function graphemeCount(s: string): number` = splitGraphemes(s).length.
- private `checkLetters(raw, max)`: t = toNfc(raw).trim(); empty if t.length === 0; space if /\s/u; digit if /\p{Nd}/u; other unless
  /^\p{L}[\p{L}\p{M}]*$/u; long only if `t.length > max && graphemeCount(t) > max` (if the UTF-16 length is within max the grapheme count is
  too, so the Segmenter is skipped); else { ok: true, text: t }.
- `export function validateSound(raw: string): TextCheck` = checkLetters(raw, SOUND_MAX_LENGTH); `export function validateName(raw: string): TextCheck` = checkLetters(raw, NAME_MAX_LENGTH).
- `export function normalizeSeed(raw: string): string | null`: t = toNfc(raw).trim(); null unless 1 <= t.length <= SEED_MAX_LENGTH and
  !/[\p{Cc}\p{Zl}\p{Zp}]/u.test(t).
- `export function upperFirst(s: string): string`: '' for ''; first code point via `String.fromCodePoint(s.codePointAt(0) as number)`,
  return `first.toUpperCase() + s.slice(first.length)` (locale-independent toUpperCase).
All regexes are anchored character classes over bounded strings (no ReDoS). Tests FIRST per <behavior>; build every non-ASCII string with
String.fromCodePoint (for the 16-grapheme combining case use 'q' + String.fromCodePoint(0x301), which has no precomposed form, so NFC keeps
two code units per grapheme and exercises the Segmenter path).
