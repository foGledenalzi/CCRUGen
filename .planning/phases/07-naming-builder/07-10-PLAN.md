```typescript
export const COLLISION_GROUPS_MAX = 2000
export const COLLISION_GROUP_MESHES_MAX = 16
export const COLLISION_SCAN_MAX_N = 4096   // the scan path refuses larger bases (RangeError); 4096 * 4095 / 2 = 8,386,560 < 2^23
export interface CollisionGroup { readonly name: string; readonly size: number; readonly meshes: readonly number[] } // meshes: lowest up to 16, ascending
export interface CollisionReport { readonly groups: number; readonly demons: number; readonly list: readonly CollisionGroup[] } // list by lowest mesh
export interface CollisionJob { readonly certified: boolean; step(shouldYield: () => boolean): CollisionReport | null } // null = call again
export function provablyUnique(sounds: readonly string[], smoothing: Smoothing): boolean
export function canCertify(naming: Naming, preset: NamingPreset | null): boolean
export function createCollisionJob(naming: Naming, preset: NamingPreset | null): CollisionJob   // RangeError for a seed-only naming or a scan above COLLISION_SCAN_MAX_N
export function findCollisions(naming: Naming, preset: NamingPreset | null): CollisionReport    // runs the job to completion
```

Create `engine/naming/collisions.ts` (relative imports only; header: "exact counts, bounded list; the engine has no clock, the app supplies
shouldYield"):
- Header paragraph (bounded exception to the engine's no-O(n^2) rule, CLAUDE.md): the scan path allocates one Float64Array and one Uint16Array
  per demon (n(n-1)/2 entries; 523,776 at the app's limit of 1024, at most 8,386,560 at COLLISION_SCAN_MAX_N = 4096, about 84 MB) and is
  therefore capped: createCollisionJob throws RangeError for a scan at base > COLLISION_SCAN_MAX_N; the certificate path allocates nothing per
  demon and has no cap. The app's NAMING_COLLISION_SCAN_MAX_N (1024) must stay <= COLLISION_SCAN_MAX_N (asserted in plan 07-20).
- `provablyUnique(sounds, smoothing)`: every sound /^[a-z]+$/; copy and sort with the default sort (code-unit order for ASCII); for each adjacent
  pair `sorted[i + 1].startsWith(sorted[i])` -> false (this also catches duplicates); then `smoothing === 0 || sounds.every(s => !/[aui]/.test(s)) || smoothingInert(sounds)`.
- `canCertify(naming, preset)`: naming.sounds !== null && !(naming.source === 'ccru' && preset !== null && preset.base === naming.base) &&
  provablyUnique(naming.sounds, naming.smoothing).
- Certified path (one step): no derived collisions exist; collisions can only involve overrides. Build `byFinal: Map<string, number[]>` for
  override texts (two equal overrides collide). For each override text X, find non-overridden demons whose derived name equals X: candidate raw
  strings are x = X with its first code point lower-cased when X starts with an upper-case ASCII letter, plus, when smoothing is 1, x with every
  a/u/i removed; split each candidate at every position 1..len-1 into p + q, look both halves up in `soundIndex: Map<sound, zone>`, form the
  demon for the join order (hi-lo: p is the higher zone; lo-hi: p is the lower zone; skip if zones are equal or the order does not match), skip
  demons that are overridden, and confirm with `resolver.nameOf(a, b) === X` (exact). Merge into groups.
- Scan path: count = base(base-1)/2. Phase A (resumable): for mesh m in order, `[a, b] = netSpanOf(m)`, name = resolver.nameOf(a, b), store
  `key[m] = hash29(name) * 8388608 + localIndex` in a Float64Array per partition, partition = first UTF-16 code unit of the name (use a
  two-pass count/place over a Uint16Array of partition ids so each partition is a contiguous subarray). Phase B: per partition (one partition
  per step check) sort its subarray, Phase C: walk adjacent equal hashes, recompute the real names of candidates and group exact equals.
  `hash29` = a 32-bit FNV-1a or murmur-style hash of the UTF-16 units of the final NFC name, `>>> 3`. localIndex < 2^23 always holds because
  scans are refused above COLLISION_SCAN_MAX_N, so count <= 4096 * 4095 / 2 = 8,386,560 < 2^23 = 8,388,608 (comment it; keep a defensive
  `count >= 2^23` RangeError and note in the comment that it is unreachable once base > COLLISION_SCAN_MAX_N is refused). Check `shouldYield()` every 512 demons
  in phase A and between partitions in B/C; return null when yielding, the report when done.
- Groups: exact `groups` and `demons`; keep at most COLLISION_GROUPS_MAX groups ordered by lowest mesh and the lowest
  COLLISION_GROUP_MESHES_MAX meshes per group (ascending), each with its exact size.
- `findCollisions` = createCollisionJob then step(() => false) until non-null.
Add the exports to engine/naming/index.ts (values and types separately). Tests FIRST per <behavior> with fast-check seed 20261020.
