<objective>
Add the versioned JSON format and its hand-written validator to the pure engine (07-RESEARCH Pattern 6, Pitfalls 10 and 17, Security
Domain), used later for export, import and the per-base localStorage slot.

Purpose: NAM-03 ("imports and exports as versioned JSON ... a file for the wrong base is rejected with a message") and D-09/D-11/D-13.
Output: `schema.ts`, `validate.ts`, the barrel lines and one test file. The UI copy for each issue is built in plan 07-11; the engine returns typed issues.

[default] decisions recorded here:
- NAMING_IMPORT_MAX_BYTES = 8 MiB (8388608; admits a full rename at base 666, research measured 3.88 MiB), NAMING_MAX_OVERRIDES = 250000, META_MAX_LENGTH = 200, ISSUES_MAX = 5, UNKNOWN_KEYS_MAX = 5.
- An unknown `generator.prng` or `generator.gen` id is refused as an unknown format version carrying that id (research suggested keeping
  the zones and disabling regeneration; refused instead so no naming exists whose seed cannot regenerate it).
- `join.smoothing` greater than EUPHONY_VERSION is an unknown format version (`euphony@{v}`); any other non-0/1 value is a bad field.
- A file without `zones` at an editable base is accepted and regenerated from its seed (or the preset when source is ccru); `locks` without `zones` is a bad field.
- Exports are pretty-printed (2 spaces) for people; slots use the compact form; both parse identically.
</objective>

File format (pretty form):
```json
{
  "schema": "ccrug.naming/1",
  "base": 28,
  "source": "generated",
  "generator": { "prng": "sfc32-cyrb128@1", "gen": "names-gen@1", "seed": "ccrug", "style": "harsh" },
  "join": { "order": "hi-lo", "smoothing": 0 },
  "zones": ["tp", "kn", "..."],
  "locks": [0, 3],
  "overrides": { "44": "Zed" },
  "meta": { "title": "", "notes": "" }
}
```
Contract created here:
```typescript
export interface SeedRecord { readonly seed: string; readonly style: StyleId; readonly join: JoinOrder; readonly smoothing: Smoothing }
export function serializeNaming(n: Naming, opts?: { readonly pretty?: boolean }): string
export type NamingIssue =
  | { readonly kind: 'not-json' } | { readonly kind: 'not-names-file' } | { readonly kind: 'too-large'; readonly maxBytes: number }
  | { readonly kind: 'unknown-version'; readonly version: string } | { readonly kind: 'wrong-base'; readonly fileBase: number }
  | { readonly kind: 'seed-only-base' } | { readonly kind: 'bad-sound'; readonly zone: number; readonly reason: TextProblem }
  | { readonly kind: 'bad-override-key'; readonly key: string } | { readonly kind: 'bad-override-name'; readonly mesh: number; readonly reason: TextProblem }
  | { readonly kind: 'bad-field'; readonly path: string }
export type NamingImport =
  | { readonly ok: true; readonly naming: Naming; readonly unknownKeys: readonly string[]; readonly unknownKeyCount: number }
  | { readonly ok: false; readonly issues: readonly NamingIssue[]; readonly issueCount: number; readonly offerSeed: SeedRecord | null }
export interface ValidateNamingOptions { readonly base: number; readonly interactiveMaxN: number; readonly preset: NamingPreset | null; readonly maxBytes?: number }
export function validateNamingJson(text: string, opts: ValidateNamingOptions): NamingImport
```
