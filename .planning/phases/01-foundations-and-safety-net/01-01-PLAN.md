Write the tests first (`tests/repo/golden-manifest.test.ts`, Vitest, `import { describe, expect, it } from 'vitest'`, importing from `'../../scripts/golden-manifest.mjs'`), run them red, then implement.

Create `scripts/golden-manifest.mjs` (ESM, zero dependencies, Windows/Linux safe; D-15: the pre-refactor baseline is never overwritten; an intentional visual change adds a NEW dated set with a written reason):
```js
#!/usr/bin/env node
// Freeze and verify golden sets (FND-02, D-15). A frozen file is never overwritten.
// Usage:
//   node scripts/golden-manifest.mjs freeze <manifest.json> --set <YYYY-MM-DD-slug> --reason "<why>" [--strict-dir <dir>] <file-or-dir>...
//   node scripts/golden-manifest.mjs verify <manifest.json>...
```
Exports (exact names; plan 01-08's `check-repo.mjs` imports `verifyManifestFile`):
- `ROOT`: repo root resolved from `import.meta.url` (`path.resolve(path.dirname(fileURLToPath(import.meta.url)), '..')`).
- `sha256(buf)`: hex digest via `node:crypto` `createHash('sha256')`.
- `toRepoPath(p)`: repo-relative path with forward slashes.
- `listFiles(...targets)`: for each target (file or directory, relative to ROOT) return repo-relative file paths; directories are walked recursively; any file named `MANIFEST.json` is skipped; result sorted with plain `<` comparison and de-duplicated.
- `emptyManifest(strictDir)`: `{ version: 1, strictDir: strictDir ?? null, sets: [] }`.
- `addSet(manifest, { set, date, reason, files })`: validation exactly as in the behavior block (set name regex `/^\d{4}-\d{2}-\d{2}-[a-z0-9-]+$/`); returns `{ ...manifest, sets: [...manifest.sets, { set, date, reason: reason.trim(), files }] }`. Error messages must contain `already exists`, `already frozen, never overwritten`, `--reason`, respectively.
- `verifyManifest(manifest, readFile, listDir)`: pure; `readFile(repoPath)` returns a Buffer or throws; `listDir(dir)` returns repo paths. Problems (strings): `missing: <file> (set <name>)`, `CR in <file>`, `changed: <file> (set <name>)`, `unfrozen file in <strictDir>: <file>`.
- `verifyManifestFile(manifestPath)`: reads the manifest JSON (a missing manifest returns `[\`manifest missing: ${manifestPath}\`]`), calls `verifyManifest` with `fs.readFileSync(path.resolve(ROOT, f))` and `listFiles`.
CLI (only when run directly: `if (process.argv[1] && import.meta.url === pathToFileURL(path.resolve(process.argv[1])).href)`):
- `freeze`: loads the manifest if it exists, else `emptyManifest(--strict-dir value)`; computes `files` as `{ repoPath: sha256 }` for `listFiles(...targets)`; refuses (exit 1) if any file contains byte 13 (`\r`); `date` = `new Date().toISOString().slice(0, 10)`; writes `JSON.stringify(next, null, 2) + '\n'`; prints `golden-manifest: froze <n> files as <set>`.
