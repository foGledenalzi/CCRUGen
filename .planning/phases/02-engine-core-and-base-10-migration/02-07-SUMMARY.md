## The lore module (shape)

```ts
// app/presets/base10/lore.ts  (line 1: // CCRU-derived lore. Not covered by the MIT license; see NOTICE.)
import type { ZoneMeta } from '../../data/types'
export interface SyzygyLore { readonly demon: string; readonly desc: string }
export interface CurrentLore { readonly name: string; readonly desc: string }
export interface GateLore { readonly desc: string; readonly detail: string }
export const ZONE_CLR: Record<number, string>          // keys 0..9, moved verbatim
export const ZONE_PARTICLE: Record<number, string>     // keys 0..9
export const PLANET_SYMBOL: Record<number, string>     // keys 0..9
export const ZONE_META: Record<number, ZoneMeta>       // keys 0..9 (planet, planetFull, desc, spinal, meshTag, door, phaseCount, lemurs, lemurian, centauri)
export const SYZYGY_LORE: Record<number, SyzygyLore>   // keyed by pair id (= low zone) 0..4
export const CURRENT_LORE: Record<number, CurrentLore> // keyed by pair id: 0 Plex, 1 Surge, 2 Hold, 3 Warp, 4 Sink
export const GATE_LORE: Record<number, GateLore>       // keyed by gate origin zone 0..9
export const DEMON_NAMES: Record<number, string>       // keyed by mesh number a(a-1)/2 + b, 0 (1::0) .. 44 (9::8)
```

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug, caught before any gate] The Write tool turned unicode escapes into raw characters**
- **Found during:** Task 2, from the identity script's escape count (seams 0, expected 5)
- **Issue:** `app/data/currents.ts` was first written through the file-write tool with the five label literals typed as `'8` + backslash-`u2212` + `1=7`; the tool decoded each escape into the real minus sign (bytes E2 88 92). The runtime string is identical, but the plan and the project rule say the escapes stay verbatim, and the count showed the difference.
- **Fix:** replaced the raw character by the six-character escape with a small script (using `chr(0x2212)` and `chr(92)`, since typing the escape in a tool argument gets decoded again), then checked the bytes (`od -c`, and `grep -c` of the escape prints 5). `lore.ts` was never affected because it was generated by a script that copies the source text. The identity script now reports 48 = 43 + 5.
- **Files modified:** `app/data/currents.ts` (before it was committed)
- **Commit:** `b14de94`

### Instruction-driven additions (not in the plan's file list)
