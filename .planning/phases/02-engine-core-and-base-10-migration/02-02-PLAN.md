Definitions (the ONLY source for the reference; from PROJECT.md "Verified numogram math", never from engine/ and never from the gitignored root `reference/` folder of local sources):
- Zones 0..n-1 for even n >= 2. Syzygy: the zones z and z' with z + z' = n - 1; pair id = its low zone lo.
- Current of the pair hi::lo flows to the zone hi - lo; the next pair is the pair containing that zone.
- Regions are the cycles of that pair map. Plex = the cycle containing zone 0. Warp = any other cycle of length 1 (a pair whose current folds into itself). Torque = every other cycle. Several Torque cycles are normal.
- Canonical order: cycles sorted by length in pairs descending, then smallest zone ascending; each cycle rotated to start at its smallest pair, then listed in flow order.
- Gate: zone k flows to the in-base digital root of the cumulation T(k) = 0 + 1 + ... + k, where the in-base digital root is obtained by repeatedly summing the base-n digits (0 stays 0).
- Demons: every unordered pair a > b of zones, enumerated a = 1..n-1, b = 0..a-1; its mesh number is its 0-based position in that enumeration (1::0 is Mesh-00). Syzygetic iff a + b = n - 1; Numodemon iff a + b = n.
- Types: both zones Torque -> chrono (syzygetic-chrono if syzygetic, else cyclic-chrono when both are in the same Torque cycle, else cross-torque-chrono); exactly one Torque -> amphi (plex-amphi or warp-amphi by the other zone's region); neither Torque -> xeno (syzygetic-xeno if syzygetic, else chaotic-xeno).

```ts
export type RefKind = 'plex' | 'warp' | 'torque'
export type RefType = 'chrono' | 'amphi' | 'xeno'
export type RefSubtype = 'cyclic-chrono' | 'cross-torque-chrono' | 'syzygetic-chrono' | 'plex-amphi' | 'warp-amphi' | 'chaotic-xeno' | 'syzygetic-xeno'
export const REF_SUBTYPES: readonly RefSubtype[] // in exactly the order above
export interface RefCycle { readonly kind: RefKind; readonly pairs: readonly number[] }   // pair ids (low zones), rotated to the smallest, flow order
export interface RefStructure {
  readonly base: number
  readonly partner: readonly number[]      // by zone
  readonly pairLo: readonly number[]       // pair index -> low zone, ascending (pair index === low zone)
  readonly current: readonly number[]      // by pair id: the zone hi - lo
  readonly nextPair: readonly number[]     // by pair id: the pair containing current[p]
  readonly cumulation: readonly number[]   // by zone k: running sum 0 + 1 + ... + k
  readonly gates: readonly number[]        // by zone k: refDigitSumRoot(cumulation[k], base)
  readonly cycles: readonly RefCycle[]     // canonical order
  readonly cycleOfZone: readonly number[]  // index into cycles
}
export interface RefDemon { readonly a: number; readonly b: number; readonly mesh: number; readonly type: RefType; readonly subtype: RefSubtype; readonly syzygetic: boolean; readonly numodemon: boolean }
export function refDigits(value: number, base: number): number[]          // repeated division, most significant first, [0] for 0
export function refDigitSumRoot(value: number, base: number): number      // while (v >= base) v = sum of refDigits(v, base); 0 stays 0
export function refStructure(base: number): RefStructure                   // throws Error for odd, < 2 or non-integer bases
export function refClassify(s: RefStructure, a: number, b: number): { type: RefType; subtype: RefSubtype; syzygetic: boolean; numodemon: boolean }
export function refDemons(s: RefStructure): RefDemon[]                     // all a > b in lexicographic order; mesh = running counter
export function refSubtypeCounts(s: RefStructure): Record<RefSubtype, number> // O(n^2) double loop over a > b calling the same rules as refClassify
```
