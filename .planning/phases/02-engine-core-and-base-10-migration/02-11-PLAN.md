- TC_EDGES: walk z = Array.from(BASE10.torques[0].zones()); edges `z.map((v, i) => [v, z[(i + 1) % z.length]])`
- TC_SYZYGIES: `Array.from(BASE10.torques[0].pairs()).map(p => [BASE10.pair(p).lo, BASE10.pair(p).hi])`
- TC_CURRENTS: `new Set(Array.from(BASE10.torques[0].pairs()).map(p => CURRENT_LORE[p].name))`
Frozen oracle: `zoneRegion`, `regions`, `tc` { zones, edges, currents (sorted), syzygies }.
