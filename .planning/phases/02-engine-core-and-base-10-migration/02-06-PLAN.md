Formulas (verbatim; n = base, o = warp first pair when Warp exists):
- plexBelow(x) = (0 < x) + (n - 1 < x); warpBelow(x) = Warp ? (o < x) + (2o < x) : 0; nonTorqueBelow(x) = plexBelow(x) + warpBelow(x); torqueBelow(x) = x - nonTorqueBelow(x).
- For Torque cycle c with ascending pair ids S_c (length L_c): zonesBelow_c(x) = #{s in S_c : s < x} + L_c - #{s in S_c : s <= n - 1 - x}; syzBelow_c(x) = L_c - #{s in S_c : s <= n - 1 - x} (pairs whose hi < x).
- within(sel, a) = demons of sel with both zones < a: chrono C(torqueBelow(a),2); amphi torqueBelow(a) * nonTorqueBelow(a); xeno C(nonTorqueBelow(a),2); syzygetic-chrono max(0, a - n/2) - (Warp and 2o < a ? 1 : 0); cyclic-chrono sum_c (C(zonesBelow_c(a),2) - syzBelow_c(a)); cross-torque-chrono C(torqueBelow(a),2) - sum_c C(zonesBelow_c(a),2); plex-amphi torqueBelow(a) * plexBelow(a); warp-amphi torqueBelow(a) * warpBelow(a); chaotic-xeno plexBelow(a) * warpBelow(a); syzygetic-xeno (Warp and 2o < a ? 1 : 0).
- row(sel, a, b) = demons (a, y) of sel with y < b: if a is Torque in cycle j with partner p = n - 1 - a: chrono torqueBelow(b); amphi nonTorqueBelow(b); syzygetic-chrono (p < b); cyclic-chrono zonesBelow_j(b) - (p < b); cross-torque-chrono torqueBelow(b) - zonesBelow_j(b); plex-amphi plexBelow(b); warp-amphi warpBelow(b); xeno and xeno subtypes 0. If a is Plex (a = n - 1): amphi and plex-amphi torqueBelow(b); xeno nonTorqueBelow(b); syzygetic-xeno (0 < b); chaotic-xeno warpBelow(b); others 0. If a is Warp (a in {o, 2o}) with partner p: amphi and warp-amphi torqueBelow(b); xeno nonTorqueBelow(b); syzygetic-xeno (p < b); chaotic-xeno plexBelow(b); others 0.
- countBelow(sel, m) for m in [0, count]: m === count ? total(sel) : ([a, b] = netSpanOf(m), within(sel, a) + row(sel, a, b)).
- at(k): RangeError unless 0 <= k < total(sel) (integer); lo = 0, hi = count - 1; while (lo < hi) { mid = Math.floor((lo + hi) / 2); if (countBelow(sel, mid + 1) > k) hi = mid; else lo = mid + 1 }; return space.at(lo) after asserting it belongs to sel (else throw Error('internal: unrank')).
