Math (verbatim): mesh of a::b (a > b) = a(a - 1)/2 + b (1::0 = 0, 2::1 = 2, 6::3 = 18, 9::8 = 44). Inverse, exact at the ceiling: `let a = Math.floor((1 + Math.sqrt(8 * m + 1)) / 2); while (a * (a - 1) / 2 > m) a--; while ((a + 1) * a / 2 <= m) a++; return [a, m - a * (a - 1) / 2]`. Do NOT compute an exact integer square root of 8m + 1: at n = 2^26, 8m + 1 reaches about 2^54 > 2^53 and is not exactly representable, so the float root is only an estimate; the correction loops are exact because a <= 2^26 - 1 keeps a(a+1) below 2^53. Classification of a > b with Torque = cycle id < torqueCount: both Torque -> chrono (syzygetic-chrono if a + b = n - 1, else cyclic-chrono if same cycle, else cross-torque-chrono); exactly one Torque -> amphi (plex-amphi if the other zone's cycle is Plex, else warp-amphi); neither -> xeno (syzygetic-xeno if a + b = n - 1, else chaotic-xeno). Numodemon iff a + b = n. Closed forms with L_c = lengthInPairs of Torque cycle c, T = sum of 2 L_c (Torque zones), W = 2 if Warp else 0, C(x,2) = x(x-1)/2: cyclic-chrono = sum(C(2L_c,2) - L_c); cross-torque-chrono = C(T,2) - sum C(2L_c,2); syzygetic-chrono = T/2; plex-amphi = 2T; warp-amphi = W*T; chaotic-xeno = Warp ? 4 : 0; syzygetic-xeno = Warp ? 2 : 1. Types: chrono = C(T,2), amphi = T(n - T), xeno = C(n - T, 2). Verified values (planner prototype, also in the frozen fixture): base 10 [12,0,3,12,12,4,2], 12 [40,0,5,20,0,0,1], 16 [28,32,6,24,24,4,2], 28 [156,108,12,48,48,4,2], 82 [1560,1404,39,156,156,4,2], 4 [0,0,0,0,0,4,2], 2 [0,0,0,0,0,0,1]. At n = 2^26: count = 2251799780130816, last mesh 2251799780130815 = (2^26 - 1)::(2^26 - 2), numodemonCount = 33554431.
